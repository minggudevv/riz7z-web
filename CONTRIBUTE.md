# Contributing to riz7z-web

Thank you for your interest in contributing to this project!

## How to Contribute

1. **Fork the repository**
2. **Create a new branch** for your feature or bugfix
3. **Make your changes**
4. **Test your changes**
5. **Submit a pull request** with a clear description of your changes

## Code Style
- Use clear and consistent code formatting
- Write descriptive commit messages
- Follow best practices for JavaScript, HTML, and CSS

## Issues
If you find a bug or have a feature request, please open an issue with detailed information.

We appreciate your contributions!
