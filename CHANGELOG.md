# Changelog

All notable changes to the RIZ7Z website project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.2.0] - 2025-10-6

### Added
- **Notification System**: Added toast notifications for copy-to-clipboard functionality
- **Enhanced Branding**: Updated all references from "R7Z" to "RIZ7Z" throughout the website
- **Symbol Information**: Added clear token symbol (R7Z) display in multiple sections
- **Comprehensive Translations**: Complete Indonesian and English translations for all components
- **Feature Descriptions**: Added detailed feature descriptions in About section with translations
- **Developer Credit**: Added "MingguDev created with ☕" credit in footer
- **LGPLv2.1 License**: Added GNU Lesser General Public License v2.1 for open source distribution
- **Documentation**: Created comprehensive CHANGELOG.md and updated README.md with license information

### Changed
- **Hero Section**: Updated main heading to display "RIZ7Z" with token symbol information
- **Navigation**: Updated navbar branding to show "RIZ7Z"
- **Footer**: Updated footer branding, added comprehensive translations, and developer credit
- **Token Information**: Enhanced token info section with symbol field and better organization
- **About Section**: Converted hardcoded feature descriptions to translatable content
- **Notification Position**: Moved toast notifications to top-left position for better UX
- **App Layout**: Improved layout structure with flexbox for proper footer positioning
- **Community Section**: Added extra padding to prevent footer overlap

### Fixed
- **Language Consistency**: Fixed all hardcoded text to use translation system
- **Copy Functionality**: Improved copy-to-clipboard with proper error handling and user feedback
- **Translation Accuracy**: Corrected and improved Indonesian translations for better readability
- **Footer Visibility**: Fixed footer not being visible due to z-index and layout issues
- **Layout Issues**: Resolved footer positioning and spacing problems

### Technical Improvements
- **Context Management**: Added NotificationContext for global notification state management
- **Component Structure**: Refactored components to use translation system consistently
- **Code Organization**: Improved code structure and maintainability
- **Z-index Management**: Proper z-index layering for footer and other components
- **Responsive Design**: Enhanced mobile and desktop layout consistency
